# CampusLink Taza

L’application est dans [`campuslink-taza/`](campuslink-taza/), le dossier racine configuré dans le projet Vercel existant.

```sh
cd campuslink-taza
npm install
npm run dev
```

La configuration, les capacités administrateur et les commandes de vérification sont détaillées dans [le README de l’application](campuslink-taza/README.md).
